A lean block theme starter with six custom server-rendered blocks and no plugin dependencies.

== Description ==

Lean Block Theme is a starting point for brochure and marketing sites. It ships six custom blocks (Hero, FAQ, Testimonials slider, Logo strip, Call to action, Stats), uses theme.json as the single source of design tokens, and loads each block's CSS only on pages that use the block.

Development notes, the build pipeline and Lighthouse results are in README.md.

== Installation ==

1. Download the ZIP from a GitHub release or the CI artifact, or clone the repository and run `npm install && npm run build`.
2. Upload it in Appearance > Themes > Add New, or copy the folder to wp-content/themes.
3. Activate the theme. Optional: insert the "Landing page" pattern on a page and switch the page to the "Landing" template.
